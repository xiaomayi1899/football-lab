# 半全场实验室 · 竞彩足球

一个纯静态手机网页，专注**竞彩足球半全场（HT/FT）**：

- **今日竞彩**：官方在售比赛的半全场 9 项赔率、市场隐含概率、泊松模型概率
- **8 个专家**：市场共识 / 泊松模型 / 价值投注 / 主队强势 / 平局派 / 冷门猎手 / ELO 等级分 / 三源融合
- **专家盈利**：有官方赔率快照且已完赛时，逐场按真实赔率结算盈亏、ROI、最大回撤
- **复盘**：每场对比「赛前推荐 → 实际半场/全场比分 → 是否命中」
- **数据**：631 场赛果的半全场分布、半场领先后走向、联赛分布

## 数据来源

中国体育彩票官方公开接口（sporttery.cn）：

- 赛果：`getUniformMatchResultV1.qry`（`sectionsNo1` 半场比分，`sectionsNo999` 全场比分）
- 赔率：`getMatchCalculatorV1.qry?poolCode=hafu`（半全场 9 项）

**官方不保留历史赔率**，所以真实盈亏从首次抓取当日起逐日累积；历史回测只统计命中率，不编造赔率。

## 本地运行

```bash
node scripts/fetch.mjs --days=45   # 抓赛果 + 今日在售赔率
node scripts/build.mjs             # 生成 data/app.json
node scripts/serve.mjs             # http://localhost:4180
```

## 诚实说明

半全场结果的分布本身偏斜（「胜胜」占约 26.8%），所以「总是选胜胜」就有 26.8% 命中率。
历史回测显示：泊松模型 27.6%、ELO 26.2%、主队强势 26.1%，**超额都不到 1 个百分点**。
足球是高度随机的运动，任何推荐都不构成投注建议。请只用可完全承受损失的小额娱乐预算。
